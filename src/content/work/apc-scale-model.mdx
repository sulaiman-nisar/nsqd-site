## Brief

Scale fabrication piece for an IDEX display case: institutional defence and
aerospace context, hard-surface build, no margin for shortcut. The piece had
to stand the run of the show and continue into a permanent display after.

## Process

Source CAD modelled to the reference vehicle and panelised for print: body,
doors, chassis, turret, wheels and dozens of detail parts mapped before any
layer ran. Large-format SLA for the body sections; fine-resolution SLA for
the detail parts (wheel hubs, hatches, hardware, running boards). Every
print pulled, supports cleaned, surfaces sanded.

Primer, base coat, weathering pass, sealer, done in-house, panel by panel.
Detail parts finished separately and bonded only after paint cured.

Delivered to the IDEX display case on schedule. Held visual through the run
of the show and went straight into a permanent display after. A second
